单 ASIN 市场分析

填入你自己的西柚洞察 MCP Token，输入一个 ASIN 和站点，页面连西柚洞察拉产品、流量、关键词、竞品和订单数据，按 100 分制算出「能不能尝试上架」的确定性。西柚接口未开放浏览器跨域时直连会被拦，此时需改走你自己的中转地址（见下方连接方式），Token 只发给西柚或你自己的中转，不经过任何公共代理。

1 · 西柚洞察 MCP Token

Token 只保存在这台设备的浏览器本地（localStorage），不上传、不共享、不会写进页面代码。换电脑或换浏览器需要重新填一次。填入你自己的 Token 后即可开始分析。

连接方式（连不上时先看这里）

西柚接口 mcp.xydc.com 没有开放浏览器跨域，网页直连会被浏览器拦下，表现就是「连不上西柚洞察接口」。这不是 Token 错，也不是你网络坏了。解决办法是走你自己的中转：用你自己的 Supabase Edge Function 或 Cloudflare Worker 转发请求，Token 只发给西柚和你自己的中转，不经过任何第三方公共代理。选「自动」时先试直连，不通再试你已填的中转地址。

填你自己部署的中转完整地址，页面会直接向这个地址发 MCP 请求，由它转发到西柚。地址里可写 {url} 作为西柚地址占位符；不写占位符就按完整中转地址直接请求。只保存在本机浏览器。还没部署中转时先留空，并按下方说明部署一个。

为什么不用公共代理：公共代理会经手你的 Token，等于把西柚账号凭证交给陌生服务器，不能用。本页只保留两条路：直连西柚，或走你自己的中转。诊断会逐条试当前通道并告诉你哪条通、哪条不通。

怎么部署我自己的中转（Supabase，约 5 分钟）
  1. 打开 supabase.com 建一个免费项目，进 Edge Functions，新建函数，名字填 xydc-proxy。
  2. 把函数代码换成下面这段并 Deploy。这段代码只做一件事：把页面发来的请求原样转发到西柚，并补上跨域头；Token 由页面带入，代码里不写任何 Token。
const CORS = { "Access-Control-Allow-Origin": "*", "Access-Control-Allow-Headers": "authorization, content-type, mcp-session-id, mcp-protocol-version", "Access-Control-Allow-Methods": "POST, OPTIONS", "Access-Control-Expose-Headers": "mcp-session-id" };
Deno.serve(async (req) => {
  if (req.method === "OPTIONS") return new Response(null, { headers: CORS });
  const r = await fetch("https://mcp.xydc.com/mcp", { method: "POST", headers: { "Content-Type": "application/json", "Accept": "application/json, text/event-stream", "Authorization": req.headers.get("Authorization") || "", "MCP-Protocol-Version": req.headers.get("MCP-Protocol-Version") || "2025-11-25", ...(req.headers.get("Mcp-Session-Id") ? { "Mcp-Session-Id": req.headers.get("Mcp-Session-Id") } : {}) }, body: await req.text() });
  const h = new Headers(CORS); h.set("Content-Type", r.headers.get("Content-Type") || "application/json"); const sid = r.headers.get("Mcp-Session-Id"); if (sid) h.set("Mcp-Session-Id", sid);
  return new Response(await r.text(), { status: r.status, headers: h });
});
  1. 部署后函数地址形如 https://你的项目.supabase.co/functions/v1/xydc-proxy，把它填到上面「我的中转地址」，通道选「只走我自己的中转地址」，点「诊断连接」显示能连通后就能正常分析了。函数的 Verify JWT 要关掉（页面请求不带 Supabase 登录凭证）。
  2. Cloudflare Worker 同理：新建 Worker，用同样的转发逻辑部署，把 Worker 地址填进来即可。

导出 HTML 文件 · 打不开怎么办

是的，这个页面本身就是一个 HTML 文件，文件名必须是 index.html，只有一个文件，不需要其他文件。点下面按钮就能下载一份干净的 index.html，可以双击用浏览器打开，也可以传到 GitHub / Vercel 部署。

下载后请确认文件名结尾是 .html，不是 .txt，也不是没有后缀。

双击打不开 / 打开是乱码或代码，按顺序查这 4 点：

  1. 文件名不对（最常见）：如果文件叫 index、index.html.txt 或 单ASIN市场分析，双击就打不开。把它重命名为 index.html。Windows 要先在文件资源管理器点「查看 → 显示 → 文件扩展名」，才能看到并改对后缀。
  2. 打开方式不对：不要用记事本、Word 打开。右键文件 → 打开方式 → 选择 Chrome 或 Edge。打开后地址栏是 file:///…/index.html，看到和本页一样的界面就是打开成功了。
  3. 在 GitHub 里点开看到的是代码：这是正常的。GitHub 只是存文件的地方，点 index.html 只会显示代码，不会变成网站。真正的网站地址是 Vercel 给的 https://xxx.vercel.app，要用那个链接打开。
  4. 点「测试连接 / 开始分析」报连不上西柚：这是西柚接口未开放跨域、浏览器直连被拦，和文件、Token 无关。解决办法只有走你自己的中转：部署一个你自己的 Supabase Edge Function 或 Cloudflare Worker 转发到西柚，把地址填到 Token 区下面的「我的中转地址」，再点「诊断连接」确认中转能通。不要用网上公共代理转发 Token，等于把凭证交给陌生服务器。本地 file:// 和部署后的 https:// 都会遇到同样的跨域问题，区别不在打开方式。

手机上：不要直接在微信里点文件预览，先下载后用 Chrome / Safari 打开，或直接打开 Vercel 的 https 链接使用。
